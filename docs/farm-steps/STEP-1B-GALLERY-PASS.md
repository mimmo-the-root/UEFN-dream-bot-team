## What the Content Drawer looks like (from the owner's screenshots)
The assets live in GALLERY folders, under `Fortnite / Galleries /`, in subfolders `Building`, `Nature`, `Props`, `Vehicle`. A gallery is a folder that holds a set of assets of the same style, for example `Farm Building Gallery`, `Frenzy Farm Barn & Shed Gallery`, `Frenzy Farm House Gallery`, `Farm Parts Gallery`, `Frenzy Farm Prop Gallery`, `Plumpton Farm Gallery`, `Nature Tree Gallery`, `Nature Tree Gallery B`, `Cuddle Tree Prop Gallery`, `Bumpy Bay Nature Gallery`. The assets inside have DIFFERENT names from the gallery (a barn is not called "barn"). The first pass items such as `Tree Large 2`, `Tree Pine 3`, `Tree Weeping Willow 01` are in `Props / Nature Tree Gallery`. Fences ("Wooden Fence A ..."), paths ("Mansion Path 1x1", "StonePath 01", "FNEC Plumpton StonePath A-D") and hedges ("Hedge Cone/Cube/Sphere/Straight" in Bumpy Bay Nature Gallery) also exist there. A nature gallery also holds rocks, cliffs, ivy and landscape pieces, not only trees. The galleries named Frenzy Farm and Plumpton Farm are the farm style: prefer them.

## The method, in this order, for every category
1. FIND THE GALLERY. List the folders under `Fortnite/Galleries` (find its real mount path first: try `/Fortnite/Galleries`, then `list_folders` on `Building`, `Nature`, `Props`, `Vehicle` one level at a time). Pick the galleries whose NAME contains the keyword (farm, barn, shed, house, tree, nature, foliage, fence, wall, path, ground, rock). Write the list of candidate galleries before looking inside.
2. FIND THE ASSET IN THAT GALLERY. List what is inside each chosen gallery (`find_assets` with that exact `folder_path`, add `asset_type` or a short `name` if the answer is large). Choose assets from ONE gallery family per category, so styles do not mix. Prefer the farm galleries; use another family only if the farm ones do not have it, and say so.
3. FIND THE REST BY ASSET NAME, THEN GO BACK TO THE GALLERY. For things you did not find in the galleries chosen (for example dirt, grass, gravel, crops, hay, well, trough, scarecrow), search by asset name with `find_assets` using `folder_path` = `Fortnite/Galleries` (or a subfolder) and a short `name`. For every hit, read the FOLDER in its path: that is the gallery that holds it. Then decide: is that gallery related to the farm and usable (same style)? List what else it contains. Do not take only the single hit.
