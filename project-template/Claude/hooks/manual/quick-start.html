Quick start

From nothing to a first working session. Do part A once per computer and part B once per project.

This page is the short path. Full installation has the long version, with every optional step.

Part A: once per computer

  1. Download the kit from the GitHub repo (green Code button, then Download ZIP) and unzip it somewhere you will remember.
  2. Let UEFN talk to Claude. In the UEFN installation folder (on Windows usually C:\Program Files\Epic Games\Fortnite), create a file named .mcp.json with this content, then start UEFN.
{
  "mcpServers": {
    "unreal-mcp": { "type": "http", "url": "http://127.0.0.1:8000/mcp" }
  }
}
  1. Turn the server on in UEFN: Edit, Editor Preferences, Model Context Protocol, then switch on Auto Start Server.
  2. Install the agents and skills. Copy everything inside the kit's user-level-agents/ folder into ~/.claude/agents/ (on Windows %USERPROFILE%\.claude\agents\). Copy each folder inside user-level-skills/ into ~/.claude/skills/. Copy user-level-memory/CLAUDE.md to ~/.claude/CLAUDE.md, or paste it at the end of yours if you already have one.
  3. Keep a copy for automatic updates. Copy the whole project-template/ folder into ~/.claude/kit-template/. From then on every new session updates the kit files of the project you are in.
  4. Register the UEFN server once by running this in a terminal:
claude mcp add --transport http unreal-mcp --scope user http://127.0.0.1:8000/mcp
You should see

claude mcp list shows unreal-mcp with scope user.

Part B: once per project

Shortcut If the project has no kit yet, open a session from its Content/ folder: the kit asks whether it is a map or a Fab product and, for a map, offers to do steps 2 to 4 for you (see A UEFN map project and A Fab product project). The steps below are the manual way.

  1. In UEFN, open Project Settings and enable Python Editor Scripting and UEFN MCP Toolsets for this project.
  2. Copy the contents of the kit's project-template/ folder into the project's Content/ folder.
  3. Open a terminal **inside that Content/ folder** and start claude.
  4. Tell it: Read Claude/SETUP-INSTRUCTIONS.md and set up this project. It checks the connection, asks what the project is, and sets up the rest.
  5. On the first session, ask for project-bootstrap. With existing code it maps the project and writes a first spec and bug list. With an empty project it asks you questions instead of inventing anything.
You should see

Open http://127.0.0.1:8765/ in your browser. The console is running, and it shows 22 agents, all idle.

Tip

Open the console as that web address, not as a file from your disk, or it cannot talk to the local server.

Your first idea

A new game starts from an idea. Tell Claude what you want to make, or ask it for ideas ("give me 5 game ideas I can finish in a few days"), then score them with /concept-card and ask for project-bootstrap to turn the best one into a plan. The steps are in A working day, section "Starting a new game: from the idea"; for the contest, see the jam chapter.

And then

Work as usual. Ask the coder agent for a feature, let the checks run, and ask the planner to update STATUS.md before you close. The next chapter, Your team, says who does what.
