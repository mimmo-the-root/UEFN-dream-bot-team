# UEFN 43.00 (1 November 2026), with 42.20 to 42.40

Source: Epic's release notes. Numbers are "notes" until confirmed in the editor.

## What breaks, and the fix
| You see | Cause | Fix |
|---|---|---|
| Name conflict on `Subscribe` or an event member in your own extension | Events (`event(t)`) are subscribable by default | Rename your extension method (unpublished code only) |
| `tag_view` warning or error | Deprecated | Use `FindCreativeObjectsWithTag` |
| Compile errors after reload on material code | Material inheritance is on; same-name extensions collide | Rename the extension or the variable |
| Camera constants missing (Scene Graph) | Removed; now Pre, Post and Presentation levels, angles in radians | Port to the levels; convert degrees |
| A basic interactable's `OnStarted` fires early | It fires at the start of a long press, not the end | Move end-of-press logic to the completion event |
| `Subscribe` result unused | It returns a `cancelable` | Keep it only if you cancel later |

## Experimental (not publishable while used)
Health and Damage Pipeline, the model NPCs (boar, chicken, raptor, wolf), Gaussian splat, the `timer` and `playable` classes. A class or device marked experimental in the digest counts too.

## Before a publish
Memory is checked at every cook in real units, 300 MB. Publishing needs two vertical thumbnails, one horizontal without text, a transparent logo, a gameplay video and the rating questionnaire (since 22 October).

## MCP in 43.00
Settings are in Editor Settings and the server starts with the editor. Tools are named one by one (`mcp__unreal-mcp__<Toolset>_<Tool>`, about 800); scripts use `async def run()` with `await execute_tool(...)`; positions are shown in LUF, tools take engine XYZ. Some tools stopped the editor when called with made-up arguments (`mcp-avoid.json`); argument names of several tools changed to camelCase.

## All details

## Verse
- Events are subscribable by default. `Subscribe` returns `cancelable`.
- New: the `clock` interface and `SecondsSinceEpochClock`; `Last[]` on arrays; `has_tags` on every creative object; `text_channel` for chat (up to 100 participants). Experimental: `playable`, `timer`.
- A field may use an earlier field as its initializer, with limits.
- `tag_view` is deprecated.
- `weak_map` limit per project module: 4 to 6.
- Asset redirectors can be reflected into the Verse manifest (setting "Reflect UE Redirectors into Verse Manifest").
- VerseVM (from 42.40): a switch in the Session menu to test the island on the new virtual machine; code reload is off with it and Live Edit is partial. Epic's roadmap puts it in Q4 2026.

## Systems
- Progression API is out of experimental: custom quests can be published. See `uefn-quests` when it exists in this kit.
- Health and Damage Pipeline: experimental, not publishable. Known limits: not every weapon damages through it, area damage only at entry, no healing with items.
- PCG in UEFN with MCP tools to create and edit graphs.
- Model NPCs (Scene Graph, experimental): boar, chicken, raptor, wolf.

## Workflow and publishing
- The Verse extension for VS Code is Lore (formerly URC): `Lore.vsix`, differences for `.uefnproject`, `.verse`, `.uplugin`.
- Memory: checked at every cook, in real units, 300 MB instead of 100 000 units; the budget is the same.
- Publishing since 22 October: two vertical thumbnails, one horizontal thumbnail without text, transparent logo, gameplay video, rating questionnaire inside the flow.
- Fab has editable "UEFN Source Assets".
