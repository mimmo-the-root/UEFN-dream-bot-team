# Retention/Discover proposals with a real outcome

One line per pattern: what was tried, on which project(s), what signal it targeted, what
actually happened. Only add an entry once there's a real outcome to report — a proposal that
hasn't been tried yet belongs in `Claude/docs/RETENTION-NOTES.md` on its own project, or in the
Obsidian second brain's `wiki/retention/` (if configured), not here.

- (example — replace) "added a mid-session objective around minute 4 to reduce bounce" — tried
  on [island], bounce rate before/after if known, or qualitative signal (e.g. "playtesters no
  longer quit right after the tutorial").

This file is the curated, kit-wide version of what the Obsidian second brain's `wiki/retention/`
wiki tracks per-article in more detail — when the second brain is configured, prefer querying it
directly for the full picture; this file is for when it isn't, or as a quick-scan summary.
