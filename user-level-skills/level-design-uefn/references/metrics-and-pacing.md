# Metrics and pacing

Write these in the plan before building and fill them from real tests, not memory.

| Metric | How to get it | Use |
|---|---|---|
| Longest clean jump | test jump on flat ground | hardest gap about 85 percent of it |
| Run speed | time a straight run of known length | arena length, how long to cross |
| Time to cross the play area | walk it | pace of fights and spawns |
| Sight distance in the arena | stand at the spawn and look | where enemies can first be seen |

Section checklist
- What is this section for (fight, rest, teach, reward)?
- What does the player see first?
- What happens if the player fails here, and how far back does it send them?
- Can a player skip it, and is that fine?
- Is there a landmark that tells where to go next?

Pacing curve for a short map (about ten minutes): teach, test, rest, combine, peak, rest, finale.
