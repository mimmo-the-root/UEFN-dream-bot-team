# Epic's editor skills served by the UEFN MCP (read 2026-11-03, UEFN 43.00)

Names only; the text is Epic's and stays in the editor. List it with `ListSkills`, read it with `GetSkills`. Epic can add or change skills in a silent update: the kit compares this list at every map (`mcp_map.py`).
