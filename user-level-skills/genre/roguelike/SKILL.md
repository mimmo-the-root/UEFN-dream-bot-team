## Known variants (prototype, to confirm/rename with real data)

Since no real roguelike maps have been analyzed yet, these 3 variants are
just a reasonable starting hypothesis for the genre — they should be
treated as placeholders, renamed or removed as soon as the first real maps
show a different classification (especially once the official Epic tags
in `~/.claude/skills/genre/fortnite-tags-known.json` are known):

1. **run-based-solo** — attempt-based runs, one player per run
2. **run-based-coop** — attempt-based runs, shared run in co-op
3. **meta-progression** — roguelike with persistent progression between runs
   (unlocks/upgrades that carry over between attempts)

Promotion rule identical to Survival: 3 maps per variant + 1 pattern
repeated in 2+ of them. `references/evidence-shared.md` stays empty until
there are at least 2 mature variants to compare.
