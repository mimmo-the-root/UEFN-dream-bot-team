# Feedback layers for a UEFN map

| Importance | Sound | Effect | Screen | Example |
|---|---|---|---|---|
| Routine | one short sound, 2-3 variants | none or tiny | none | picking up a coin |
| Good | clear sound | small burst at the spot | short line or number | delivering an item |
| Big | stinger or jingle | larger effect, optional second effect | big line for 2-3 seconds | round won, boss down |
| Failure | low, short sound | none | calm line, no shouting | falling, losing a life |

Notes
- Sound and effect belong together: a device that plays both on the same event keeps them in sync.
- Use the audio player and effects devices already in the map; place them near the action, not in a far corner.
- Score text: show the new total, not only "+1".
- A countdown reads better with a tick each second for the last three.
- Test with headphones off once: the effect must carry the event alone.
- Do not add a cue to an event you cannot trigger twice in a row without it becoming noise.
