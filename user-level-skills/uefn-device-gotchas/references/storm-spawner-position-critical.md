# Position-critical devices — never relocate these

These devices' WORLD POSITION is itself gameplay data, not just placement. Per
`~/.claude/CLAUDE.md` rule 7's gameplay-critical-position exception: never move one onto a
DemoDisplay stand or anywhere else for organizational reasons — reference it by name in the
matching DemoDisplay's description instead, and always check position-criticality before moving
ANY device, not just the ones already listed here.

- **Storm Controller / Beacon**: its position is the storm circle's center. Moving it changes
  where the storm actually closes to, in-game, not just where it sits in the Outliner.
- **Player Spawner**: its position is the spawn point. Same caveat.
- (example — replace) any other device found, on this project or another, where moving it
  changed observable in-game behavior — name the device and what broke.

If in doubt about a device not listed here, check its behavior with a harmless test move before
assuming it's safe to relocate, or ask the owner.
